# Student Management System

A Student Management System is a Python-based software application for managing student records. It allows users to add, view, search, update, and delete student information.

## Main Features

- **Add Student:** Store student details.
- **View Students:** Display all student records.
- **Search Student:** Find a student using their ID.
- **Update Student:** Edit student details.
- **Delete Student:** Remove a student record.

## Tech Stack

- **Language:** Python
- **Platform:** VS Code

## Concepts Demonstrated

- Classes and Objects
- Functions and Methods
- Loops and Conditional Statements
- Dictionaries
- Input Validation
- Exception Handling

## How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open `project.py`.
4. Run the program using the Python interpreter.

Alternatively, run it from the terminal:

```bash
python project.py
```
